# DivineGuard Client Portal

**Full-stack SaaS customer portal**

## Overview

A full-stack SaaS customer portal for support tickets, cybersecurity assessments, users, reports, projects, subscriptions, and service requests.

## Tech Stack

- Next.js
- TypeScript
- PostgreSQL
- Authentication
- Docker
- Azure
